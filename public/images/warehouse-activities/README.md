# Sata Inggil Warehouse Activity Images

Folder ini disiapkan untuk aset gambar aktivitas gudang tembakau yang dibuat/generated khusus untuk UI Sata Inggil.

Rekomendasi nama:
- tobacco-receiving.webp
- tobacco-sorting.webp
- tobacco-storage.webp
- tobacco-weighing.webp
- tobacco-quality-check.webp
- tobacco-loading.webp
- tobacco-unloading.webp

Format utama: WebP, rasio 16:9 atau 4:3. Gunakan gambar realistis, aman untuk komersial, dan hindari logo/merek pihak ketiga yang tidak relevan.
